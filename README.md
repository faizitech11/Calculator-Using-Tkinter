# 🧮 Advanced Calculator (Python Tkinter)

A modern desktop calculator built with **Python** and **Tkinter**. This calculator provides a clean graphical interface and supports basic arithmetic operations along with advanced functions like square, square root, percentage, and parentheses.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/faizitech11/calculator.git
```

### Move into the Project Folder

```bash
cd calculator
```

### Run the Application

```bash
python calculator.py
```

---

## 📖 How to Use

1. Enter numbers using the calculator buttons.
2. Select an operator (+, -, ×, ÷).
3. Press **=** to calculate.
4. Use:
   - **C** → Clear
   - **⌫** → Delete last character
   - **√** → Square Root
   - **x²** → Square
   - **%** → Percentage
